# Ernest v0.1.0-alpha

Ernest `v0.1.0-alpha` is the first public alpha of the AI provenance and blockchain anchoring PoC.

## Highlights

- SvelteKit dashboard as the official frontend.
- NestJS 11 backend with MongoDB-backed hashchain storage.
- Optional Sepolia anchoring through `ErnestMerkleAnchor`.
- API key protection for public demo write endpoints.
- pnpm workspace with reproducible JavaScript installs.
- Docker Compose local stack for demos and small VPS deployments.
- GHCR image publishing for backend and frontend.
- Go CLI, Rust Merkle helper, Python demo sandbox, and optional auditor agent.

## Images

After the `Publish Images` workflow runs, deployable images are expected at:

- `ghcr.io/ccastromar/ai-blockchain-provenance-backend:v0.1.0-alpha`
- `ghcr.io/ccastromar/ai-blockchain-provenance-frontend:v0.1.0-alpha`

For a mutable demo deployment, `latest` can be used. For release deployments, prefer the version tag.

## Deploy

```bash
docker login ghcr.io
ERNEST_IMAGE_TAG=v0.1.0-alpha docker compose -f docker-compose.prod.yml pull
ERNEST_IMAGE_TAG=v0.1.0-alpha docker compose -f docker-compose.prod.yml up -d
./scripts/deploy-check.sh
```

## Alpha Limitations

- Not a production compliance system.
- No full user authentication.
- No RBAC or tenant isolation.
- Public-chain anchoring requires funded Sepolia credentials and is not exercised in CI.
- Browser demo API keys are public in the frontend bundle and are not production secrets.
